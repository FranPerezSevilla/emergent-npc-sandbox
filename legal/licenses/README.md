# License Evidence

Store license/copyright/notice evidence here when doing so is useful and permitted by the source terms.

Examples:

- copied LICENSE/NOTICE files from software dependencies when distribution requires them;
- text supplied with an asset pack that must be preserved;
- purchase/license evidence that is safe to keep in the private repository;
- a dated snapshot/note describing which terms were reviewed.

Do **not** store secrets, account credentials, purchase tokens or private personal data here.

If license text should not or cannot be copied into the repository, keep a stable `licenseUrl` / source URL and review date in `legal/third-party.json` instead.

File names should normally begin with the corresponding third-party registry ID so evidence remains traceable.
